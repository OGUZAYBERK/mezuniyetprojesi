# 🌍 CLIMPACT

### Akıllı Karbon Ayak İzi ve İklim Farkındalığı Platformu

CLIMPACT, kullanıcıların karbon ayak izlerini hesaplamalarına, çevreye etkilerini anlamalarına ve daha sürdürülebilir alışkanlıklar kazanmalarına yardımcı olmayı amaçlayan akıllı bir web platformudur.

## 🎯 Projenin Amacı

İklim değişikliğiyle mücadelede yalnızca bilgi edinmek yeterli değildir. İnsanların günlük alışkanlıklarını fark etmeleri ve bunları daha çevre dostu hâle getirmeleri de önemlidir.

CLIMPACT, kullanıcıların kendi çevresel etkilerini görmelerini, azaltma yollarını öğrenmelerini ve zaman içindeki gelişimlerini takip etmelerini hedefler.

## ⚙️ Planlanan Özellikler

### 1. Karbon Ayak İzi Hesaplama
- Kullanıcı son 7 gündeki alışkanlıklarını girer.
- Ulaşım, enerji ve tüketim gibi kategoriler değerlendirilir.
- Haftalık karbon ayak izi hesaplanır.

### 2. Sonuçlar ve Grafikler
- Hesaplama sonuçları grafiklerle gösterilir.
- Kategorilere göre emisyon dağılımı incelenebilir.
- Kullanıcı hangi alanlarda daha fazla emisyona neden olduğunu görebilir.

### 3. Yapay Zekâ Destekli Analiz
- Yapay zekâ hesaplama sonuçlarını yorumlar.
- En fazla emisyona neden olan alışkanlıkları açıklar.
- Kullanıcıya kişiselleştirilmiş öneriler sunar.

### 4. Çevre Dostu Görevler
- Kullanıcı haftalık çevre görevleri tamamlayabilir.
- Görevlerin tamamlanma durumu takip edilir.
- Kullanıcının çevre dostu alışkanlıklar kazanması desteklenir.

### 5. Haftalık Gelişim Takibi
- Kullanıcı her hafta yeniden hesaplama yapabilir.
- Önceki haftalarla karşılaştırma yapılabilir.
- Karbon ayak izindeki değişim takip edilir.

### 6. Simülasyon
- Kullanıcı alışkanlıklarını değiştirdiğinde sonuçların nasıl etkileneceğini görebilir.
- Farklı senaryolar karşılaştırılabilir.
- Simülasyon sonuçları gerçek ölçümlerden ayrı tutulur.

### 7. Hedef Belirleme
- Kullanıcı kendisine çevresel hedefler belirleyebilir.
- Hedeflere ulaşma durumu takip edilir.
- Haftalık gelişim değerlendirilebilir.

## 🧠 Teknik Yaklaşım

- Karbon ayak izi hesaplamaları belirlenmiş emisyon katsayılarına dayanacaktır.
- Hesaplama motoru yapay zekâdan bağımsız çalışacaktır.
- Yapay zekâ hesaplama sonuçlarını yorumlamak ve öneriler sunmak için kullanılacaktır.
- Simülasyonlar gerçek kullanıcı verilerini değiştirmeyecektir.
- Haftalık karşılaştırmalar kaydedilmiş gerçek hesaplamalara dayanacaktır.

## 🛠️ Teknolojiler

Planlanan teknoloji altyapısı:

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Yapay zekâ API entegrasyonu
